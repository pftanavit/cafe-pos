# Product overview

Cafe POS is a point-of-sale prototype for managing cafe orders, menu items, ingredient inventory, discounts, and order activity.

## User roles

- **Administrators** manage menu items, ingredients, discount codes, and analytics.
- **Employees** create and process orders, manage the order queue, and update inventory quantities.
- **Customers** browse the menu, apply discount codes, place orders, and follow order status.

## Implementation status

This document describes the intended product scope; it is not a complete API or behavior specification. Refer to the backend routes and client screens for the current implementation. Some workflows may be incomplete or differ from this initial scope.

The backend currently has no request authentication or authorization. Use only isolated development data until access controls and production safeguards are implemented.
